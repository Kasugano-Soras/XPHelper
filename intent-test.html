intent 测试页

用手机/PC 放到车机能访问的 http 地址（不要用 file:// 打开，Chrome 会拦）。每点一次看是否有反应：弹“打开应用”或直接跳页 = 成功；静默/提示无法打开 = 该形式不被支持。

1. 打开 devtools 的默认入口（只按包名） intent://#Intent;action=android.intent.action.MAIN;package=com.xiaopeng.devtools;end 2. 直指工程模式页（component，只有老壳/自解析 intent 的壳才认） intent://#Intent;component=com.xiaopeng.devtools/.view.usersettings.UserSettingsActivity;end 3. 直开安装器装 APK（component + file://，需要壳 targetSdk<24 才可能过） intent:///sdcard/Download/XPHelper-2.0.apk#Intent;scheme=file;type=application/vnd.android.package-archive;action=android.intent.action.VIEW;component=com.android.packageinstaller/.PackageInstallerActivity;end 4. 同上，但不指定 component（按包名解析） intent:///sdcard/Download/XPHelper-2.0.apk#Intent;scheme=file;type=application/vnd.android.package-archive;action=android.intent.action.VIEW;package=com.android.packageinstaller;end 5. 只打开安装器界面（无 data，看它认不认这个包）

提示：第 3/4 条能否成功，取决于车机壳的 targetSdk——Android 7+ 跨应用传 file:// 会被 FileUriExposedException 拦下，老壳（targetSdk<24）才放行。若第 3 条能弹安装界面但提示“无法安装未知来源”，说明卡在调用方身份上，网页这条路走不通。
